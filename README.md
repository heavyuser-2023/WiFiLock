# 와이파이 잠금 (WiFiLock)

와이파이 연결 상태에 따라 **자동 화면 잠금 시간**을 바꿔 주는 앱입니다. **맥·윈도우·리눅스**를 지원합니다.

- 집·사무실처럼 등록한 네트워크에서는 길게(예: 30분), 카페 같은 낯선 와이파이에서는 짧게(예: 5분), 와이파이가 없으면 더 짧게(예: 3분) 잠급니다.
- 키보드·마우스 입력이 없는 시간을 재서, 정한 시간이 지나면 운영체제의 화면 잠금을 실행합니다.
- 맥은 화면 오른쪽 위 메뉴 막대, 윈도우는 오른쪽 아래 알림 영역, 리눅스는 상태 아이콘 영역에 **자물쇠 달린 모니터 아이콘**이 나타납니다.

## 내려받기

[최신 릴리스](https://github.com/heavyuser-2023/WiFiLock/releases/latest)에서 운영체제에 맞는 파일 하나를 내려받습니다.

| 운영체제 | 파일 | 설치 방법 |
| --- | --- | --- |
| 맥 11 이상 (애플 실리콘·인텔) | `WiFiLock_<버전>_universal.dmg` | 열어서 `WiFiLock` 을 응용 프로그램 폴더로 끌어다 놓기 |
| 윈도우 10·11 (x64) | `WiFiLock_<버전>_x64-setup.exe` | 더블 클릭 → 한국어 설치 화면. 관리자 권한 필요 없음 |
| 윈도우 10·11 (x64) | `WiFiLock_<버전>_x64_en-US.msi` | 회사 배포 도구용 |
| 우분투·데비안 (x64) | `WiFiLock_<버전>_amd64.deb` | `sudo apt install ./WiFiLock_<버전>_amd64.deb` |
| 페도라 등 (x64) | `WiFiLock-<버전>-1.x86_64.rpm` | `sudo dnf install ./WiFiLock-<버전>-1.x86_64.rpm` |
| 그 밖의 리눅스 (x64) | `WiFiLock_<버전>_amd64.AppImage` | 실행 권한을 주고 바로 실행 |

애플 공증·윈도우 코드 서명을 받지 않은 파일이라 처음 열 때 경고가 나옵니다.
- 맥: 경고 창을 닫고 시스템 설정 > 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누릅니다.
- 윈도우: "Windows의 PC 보호" 창에서 **추가 정보** → **실행**을 누릅니다.

릴리스마다 `SHA256SUMS.txt` 가 함께 올라가 있어 내려받은 파일이 온전한지 확인할 수 있습니다.

## 처음 실행할 때

1. 와이파이 이름을 읽을 수 있게 권한을 허용합니다.
   - **맥**: 위치 권한 요청이 나오면 **허용**. 맥은 위치 권한이 있는 앱에만 와이파이 이름을 알려 줍니다.
   - **윈도우 11 24H2 이상**: 설정 > 개인 정보 및 보안 > 위치에서 위치 서비스와 "데스크톱 앱이 위치에 액세스하도록 허용"을 켭니다.
   - **리눅스**: 따로 허용할 것이 없습니다.

   위치 정보 자체는 쓰지도, 저장하지도, 밖으로 보내지도 않습니다. 권한이 없으면 "와이파이 연결됨"과 "연결 안 됨"만 구분해 기본 잠금 시간을 적용합니다.
2. 설정 창에서 **현재 네트워크 추가**로 집·사무실 네트워크를 등록하고 잠금 시간을 고릅니다.
3. **로그인할 때 자동으로 실행**을 켜 두면 컴퓨터를 켤 때마다 자동으로 동작합니다.

## 동작 규칙

- 잠그기 전에 화면 위쪽에 경고 창을 띄웁니다(기본 10초 전). 마우스나 키보드를 움직이면 취소됩니다. 경고는 잠금 시간의 절반을 넘지 않습니다.
- 동영상 재생·발표·화상 회의처럼 앱이 화면을 켜 두도록 요청한 동안은 잠금을 미룹니다.
- 와이파이가 잠깐 끊기는 경우를 대비해, 잠금 시간이 **짧아지는** 변화는 15초 동안 이어질 때만 적용합니다. 길어지는 변화는 바로 적용합니다.
- 한 번 자리를 비운 동안에는 한 번만 잠급니다. 잠금 해제나 잠자기에서 깨어난 뒤에는 그 시각부터 다시 셉니다.
- 공유기 주소까지 기록된 네트워크는 이름이 같아도 공유기가 다르면 다른 네트워크로 봅니다 (흔한 기본 이름의 와이파이를 착각하지 않도록).
- 운영체제 자체의 잠금(화면 보호기, 디스플레이 끄기, 절전, 회사 정책)과 이 앱은 따로 동작하며 **먼저 오는 쪽이 잠급니다.** 운영체제 쪽이 이 앱에서 정한 시간보다 짧으면 설정 창에서 어떤 설정을 얼마로 바꾸면 되는지 알려 줍니다.

## 운영체제별 차이

| 기능 | 맥 | 윈도우 | 리눅스 (그놈·KDE + systemd) |
| --- | --- | --- | --- |
| 와이파이 이름 | 위치 권한 필요 | 윈도우 11 24H2부터 위치 권한 필요 | 네트워크매니저에서 바로 읽음 |
| 동영상 재생 중 보류 | 어떤 앱인지 이름까지 표시 | "다른 앱"으로 표시 | 그놈·logind·KDE 가 알려 주는 요청 |
| 메뉴 아이콘 옆 남은 시간 (분 단위·초 단위 선택) | 지원 | 지원하지 않음 | 데스크톱에 따라 다름 |
| 아이콘 | 다크 모드에 맞춰 색이 바뀜 | 색 바탕 그림 | 색 바탕 그림. 그놈은 "AppIndicator" 확장이 있어야 보임 |

자리비움 시간을 읽을 수 없는 리눅스 데스크톱(일부 웨이랜드 환경)에서는 메뉴에 그렇다고 알리고 잠그지 않습니다. 자세한 내용과 제거 방법은 [cross/README.md](cross/README.md)를 보세요.

## 개발

2.0 은 러스트와 타우리 2로 만들었고, 소스는 [`cross/`](cross/README.md) 폴더에 있습니다.

```
cross/core       운영체제와 무관한 핵심 로직 (세 운영체제 공통) + 단위 테스트
cross/platform   운영체제별 시스템 기능 (맥·윈도우·리눅스)
cross/app        타우리 앱: 메뉴 아이콘·메뉴, 설정 창, 경고 창, 자가 진단
cross/ui         설정 창·경고 창 화면 (세 운영체제 공통)
```

```bash
cd cross && npm ci && cargo test --workspace && npx tauri build
```

`rust-tauri` 브랜치에 올리면 깃허브 자동 빌드(`.github/workflows/cross-build.yml`)가 맥·윈도우·리눅스 서버에서 테스트, 정적 검사, 설치 파일 빌드, 자가 진단을 차례로 돌리고 설치 파일을 결과물로 올립니다.
