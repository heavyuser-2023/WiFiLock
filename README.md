# 와이파이 잠금 (WiFiLock)

와이파이 연결 상태에 따라 **자동 화면 잠금 시간**을 바꿔 주는 macOS 메뉴 막대 앱입니다.

- 집·사무실처럼 등록한 네트워크에서는 길게 (예: 30분), 카페 같은 낯선 와이파이에서는 짧게 (예: 5분), 와이파이가 없으면 더 짧게 (예: 3분)
- 키보드·마우스 입력이 없는 시간을 재서 정한 시간이 지나면 macOS 의 "화면 잠금"을 실행합니다 (⌃⌘Q 와 같은 동작)
- 화면 오른쪽 위 메뉴 막대에 **자물쇠가 달린 화면 아이콘**이 표시됩니다 (쉬는 중이면 열린 자물쇠)

## 설치

macOS 13 이상, 애플 실리콘과 인텔 맥 모두 지원합니다.

[릴리스 페이지](https://github.com/heavyuser-2023/WiFiLock/releases/latest)에서 설치 파일을 내려받습니다. 둘 중 하나만 쓰면 됩니다.

| 파일 | 방법 |
| --- | --- |
| `WiFiLock-1.0.0.pkg` | 더블 클릭 → 설치 안내를 따라 진행. `/Applications` 에 설치되고 끝나면 바로 실행됩니다. 관리자 암호가 필요합니다. |
| `WiFiLock-1.0.0.dmg` | 열어서 `WiFiLock` 을 옆의 `Applications` 폴더로 끌어다 놓은 뒤 실행합니다. |

배포 파일은 애플 공증을 받지 않았습니다. 처음 열 때 "확인되지 않은 개발자", "악성 코드가 없는지 확인할 수 없음" 같은 경고가 나오면:

- macOS 15 이상: 경고 창을 닫고 시스템 설정 > 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누른 뒤 암호를 입력합니다.
- macOS 13~14: 파일을 Control-클릭(오른쪽 클릭) → **열기**를 누릅니다.
- 그래도 열리지 않으면 터미널에서 다운로드 표시를 지웁니다.

```bash
xattr -dr com.apple.quarantine /Applications/WiFiLock.app
```

소스에서 직접 빌드하려면 아래 [개발](#개발) 항목을 보세요.

## 처음 실행할 때

1. 위치 권한 요청이 나오면 **허용**을 누릅니다. macOS 는 위치 권한이 있는 앱에만 와이파이 이름을 알려 주기 때문입니다. 위치 정보 자체는 쓰지도, 저장하지도, 밖으로 보내지도 않습니다.
2. 설정 창이 열리면 **현재 네트워크 추가**로 집·사무실 네트워크를 등록하고 잠금 시간을 고릅니다.
3. **로그인할 때 자동으로 실행**을 켜 두면 컴퓨터를 켤 때마다 자동으로 동작합니다.

위치 권한을 허용하지 않아도 앱은 동작합니다. 이때는 네트워크 이름을 구분하지 못하므로 "와이파이 연결됨"(등록되지 않은 와이파이 시간)과 "연결 안 됨"(와이파이 없음 시간) 두 가지로만 잠금 시간을 바꿉니다.

## 메뉴 막대 메뉴

| 항목 | 설명 |
| --- | --- |
| 와이파이: … | 지금 연결된 네트워크 |
| 잠금 시간: … | 지금 적용 중인 잠금 시간과 그 근거 (등록된 네트워크 / 등록되지 않은 네트워크 / 연결 없음) |
| 잠금까지 m:ss 남음 | 실시간 남은 시간 (일시 중지·보류 중이면 그 상태) |
| 지금 잠그기 (⌘L) | 바로 화면을 잠급니다 |
| 자동 잠금 사용 | 자동 잠금 켜기/끄기 |
| 일시 중지 | 30분 / 1시간 / 2시간 / 4시간 / 다시 시작할 때까지 |
| 현재 네트워크를 등록 | 등록되지 않은 네트워크에 연결된 경우에만 표시 |
| 설정… (⌘,) | 설정 창 |
| 와이파이 잠금 정보 | 버전 정보 |
| 종료 (⌘Q) | 앱 종료 |

## 설정

- **일반**: 자동 잠금 사용, 로그인할 때 자동으로 실행
- **현재 네트워크**: 연결 상태, 지금 적용 중인 규칙, 위치 권한 안내
- **네트워크별 잠금 시간**: 등록한 네트워크 목록 (이름 바꾸기, 시간 선택, 삭제). "이름으로 추가…"로 와이파이 이름을 직접 입력해 등록할 수도 있습니다. "잠그지 않음"도 고를 수 있습니다.
- **기본 잠금 시간**: 등록되지 않은 와이파이, 와이파이 꺼짐·연결 안 됨
- **고급**
  - 잠그기 전에 화면에 경고 표시 (기본 10초 전): 마우스나 키보드를 움직이면 취소됩니다.
  - 동영상 재생 중에는 잠그지 않기: 앱이 화면을 켜 두도록 요청한 동안(동영상, 발표, 화상 회의 등)은 잠금을 미룹니다. 메뉴에 어떤 앱 때문에 보류 중인지 표시됩니다.
  - 메뉴 막대에 남은 시간 표시

### 동작 규칙

- 자리를 비운 동안 와이파이가 바뀌어 더 짧은 시간이 적용되면(예: 집 30분 → 연결 끊김 3분), 이미 시간이 지났더라도 바로 잠그지 않고 경고를 먼저 띄운 뒤 잠급니다.
- 한 번 자리를 비운 동안에는 한 번만 잠급니다. 다시 사용하기 시작하면 시간을 새로 셉니다.
- 화면이 이미 잠겨 있거나 빠른 사용자 전환으로 다른 사용자가 쓰는 중이면 아무것도 하지 않습니다.
- 와이파이가 잠깐 끊기는 경우를 대비해, 잠금 시간이 **짧아지는** 변화는 15초 동안 이어질 때만 적용합니다. 길어지는 변화는 바로 적용합니다.
- 잠금 해제·잠자기에서 깨어남은 "자리에 돌아옴"으로 보고 그 시각부터 다시 셉니다 (애플워치로 풀어도 곧바로 다시 잠기지 않음).
- 경고는 잠금 시간의 절반을 넘지 않습니다 (예: 잠금 30초면 경고는 최대 15초).
- 공유기 주소까지 기록된 네트워크는 이름이 같아도 공유기가 다르면 다른 네트워크로 봅니다 (흔한 기본 이름의 와이파이를 착각하지 않도록).

## 제거

1. 메뉴에서 **종료**
2. `/Applications/WiFiLock.app` 을 휴지통으로
3. (선택) 설정 지우기:

```bash
defaults delete com.wifilock.WiFiLock
```

로그인 항목은 앱을 지우면 함께 사라집니다. 시스템 설정 > 개인정보 보호 및 보안 > 위치 서비스 목록에 남은 항목은 직접 지울 수 있습니다.

## 개발

필요한 것: Xcode (Swift 5.9 이상), macOS 13 이상 대상

```bash
./scripts/build.sh
```

단위 테스트 → 범용(애플 실리콘 + 인텔) 릴리스 빌드 → 아이콘 생성 → 앱 번들 조립 → 서명 → `dist/` 에 DMG·PKG 생성.
서명은 Developer ID → Apple Development → 임시 서명 순으로 자동 선택하며 `SIGN_IDENTITY` 로 지정할 수 있습니다. 공개 배포 파일은 개인 인증서 정보가 들어가지 않도록 임시 서명(`SIGN_IDENTITY=- ./scripts/build.sh`)으로 만듭니다. 버전은 `VERSION=1.1.0 ./scripts/build.sh` 처럼 바꿉니다 (빌드 번호는 빌드 날짜·시각으로 자동 지정).

```bash
./scripts/verify.sh
```

앱 번들 구조·서명 확인 → 앱을 실제로 띄워 자가 진단(메뉴, 아이콘 위치, 설정 창, 경고 창, 잠금 시나리오 등. 실제 잠금은 하지 않음) → DMG·PKG 내용 확인.
자가 진단 결과와 화면 그림은 `build/verify/selftest/` 에 남습니다.

```bash
swift test
```

핵심 로직(규칙 선택, 잠금 시점 계산, 설정 저장) 단위 테스트만 실행합니다.

### 구조

```
Sources/WiFiLockCore/     시스템에 의존하지 않는 로직 (단위 테스트 대상)
  Settings.swift          설정·네트워크 규칙 모델
  Policy.swift            와이파이 상태 → 잠금 시간 결정
  LockScheduler.swift     자리비움 시간 → 경고·잠금 시점 결정 (상태 기계)
  SettingsStore.swift     설정 저장 (UserDefaults)
  Formatting.swift        한글 시간 표기
Sources/WiFiLock/         메뉴 막대 앱
  AppDelegate.swift       앱 조립, 첫 실행 처리
  LockController.swift    1초마다 상태를 읽어 잠금 실행
  WiFiMonitor.swift       와이파이 감시 (CoreWLAN, 위치 권한)
  SystemProbes.swift      자리비움 시간, 화면 잠김 여부, 화면 유지 요청, 화면 잠금 실행
  StatusBarController.swift  메뉴 막대 아이콘과 메뉴
  SettingsView.swift      설정 창 (SwiftUI)
  WarningHUD.swift        잠금 직전 경고 창
  LaunchAtLogin.swift     로그인 시 자동 실행
  SelfTest.swift          자가 진단 (--self-test)
scripts/                  빌드·검증·아이콘 생성
packaging/                PKG 설치 프로그램 구성
```

### 개발용 실행 인자

| 인자 | 설명 |
| --- | --- |
| `--dry-run` | 실제로 잠그지 않고 기록만 남김 |
| `--log-file <경로>` | 기록을 파일로도 남김 |
| `--settings-suite <이름>` | 별도 설정 저장소 사용 |
| `--override-timeout <초>` | 모든 네트워크의 잠금 시간을 강제로 지정 |
| `--no-location-prompt` | 시작할 때 위치 권한을 묻지 않음 |
| `--open-settings` | 시작하자마자 설정 창 열기 |
| `--self-test <폴더>` | 자가 진단 후 종료 |
